本机使用同一段 617 帧、30 Hz、两路 640×480 的真实录制做离线重放，约 20.6 秒。旧流程基准已测得 71.70 秒，其中临时 PNG 写入等待约 53.07 秒。新版结果如下，耗时不包含首次导入依赖：

| 阶段 | 耗时 |
| --- | --- |
| 30 Hz 重放到新版录制器 | 20.534 秒，写入队列最大 1 帧，队列满次数 0 |
| 每个同步样本的双相机编码和表格处理 | 平均 9.80 ms，P95 10.64 ms |
| 结束录制收尾 | 0.069 秒 |
| 新录制格式导出，含校验、复制和重新编号 | 0.104 秒 |
| 旧 HDF5 经优化后的兼容导出 | 9.422 秒 |

该片段原始 HDF5 为 92.66 MB，新版 Parquet、MP4、元数据及诊断合计 26.01 MB。以上是本机 NVMe、缓存可用时的单段实测，不是其他硬件或任意数据量的性能保证；完整质检仍需解码检查视频。没有测试真实遥操与相机采集同时运行时的资源竞争，也没有运行模型训练。
